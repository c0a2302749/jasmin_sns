## 3. 留保事項（論文を書く前に判断が必要）

### 3.1 `checks.parquet` の `W0_IDENTICAL` 行は本パイプラインでは恒真

`src/run/experiment.py:80-82` が `if W == 0.0: treat_record = ctrl_record` と
**同一オブジェクトを再利用**するため、`W_values` に 0.0 を含む限り `W0_IDENTICAL` は
自分自身を比べて PASS になる。`ABL_SYS_BITWISE` は独立実行なので恒真ではないが、
`W0_IDENTICAL` は証拠にならない。

本レポートの check 5/6 は `run_arm` を2回独立に呼んで**パイプラインをバイパス**して
判定しており、そちらが実際の証拠である。`experiment.py` で `W == 0.0` のとき treat も
再実行させる（あるいは `treat_record = ctrl_record` であることを `detail` に明示する）
のが望ましい。

### 3.2 `ABL-REACT` は「リアクタンス無効化」ではなく「減衰の飽和」

設計書 A9 は「k=0 では `W_eff = min(W, θ)` の飽和のみとなり、リアクタンスによる減衰が
消える」と書くが、閉形式 `W_eff = max(0, W − (1+k)·max(0, W−θ))` に `k=0` を代入すると
`W_eff = min(W, θ_react)` になり、**θ_react < W の参加者は依然として減衰を受ける**
（W=1.0 では 100/100 人の W_eff が θ で頭打ち）。

実装は設計書の記述どおりである（check 10 で 2.8e-17 の精度で一致）。
ただし「リアクタンスを無効化した」という表現のまま書くと機構を誤って説明する。
A9 の文言を「鏡像減衰の係数を 0 にする（超過分は θ で頭打ちになる）」に直すか、
「無効化」を目的とするなら閉形式側を変更する必要がある。

### 3.3 C3 に合否判定が存在しない

`src/analysis/persona_select.py` は `C3_reactance_discriminability_by_persona` を
**算出するが `C3_pass` を持たない**。`scripts/select_persona.py:43` の `passed()` も
C1/C2/C4 しか見ないため、設計書②の閾値（反発型 ≥50%、同調型 ≤20%）はコード上
**強制されていない**。今回は手動で照合して両表とも満たすと判断したが、
閾値をコードで強制することを推奨。

### 3.4 C2 の分母を T_max*n に統一（修正済み）

`persona_select.criteria` の `total_cells` は当初 `(T_max + 1) * n` で、`n_clipped_R` が数える
ターン 1..T_max の `T_max * n` セルと不一致だった（クリップ率を約0.2%過小評価、保守側）。
分母を `T_max * n` に修正し、`analyze_dose_response.py` / `negative_controls.py` と揃えた。
W=0 の結論は変わらない。

ただしこれは副次問題である。**C2 の問題は分母ではなく「W=0 でのみ測っている」という
適用範囲のほうが大きい**（§4.4）。

### 3.5 投与量反応が単調でない

**結論は §4.6 のペルソナ別結果（Q7）に置き換える。** 要点: clip が原理的に起きない
`independent` と `reactant` の転数は、W=0.05→0.45 で単調増加し、
W=0.45–0.55 で 0.05133 の平台を取り、W=0.60 から減少して
W=1.0 で 0.03267 まで減衰する（36.4% 減）。同時 `W_eff=0` 率は 74.80% で、
同群の観測 clip は全点 0 セルである。したがってこの群自身の山は天井では説明できない。
ただし不可能群は `R` の可動域自体が狭い点は留保する。
なお §4.3 の三分位分解は clip 可否の異なる型を混ぜるため、寄与度の数字は無効とする。
介入側で天井が再発すること（§4.4、W=0.65–0.85 で C2 の 5% 超過）は別事実として残る。

### 4.2 Q2 — 機構は設計どおりか（実装ミスではなく式の問題か）

**完全に一致する。** 2 段階とも例外ゼロ。

| 検証 | 結果 |
|---|---|

ことが機械的に確認できた。設計書 A13 の記述（`W = 2θ` で 0 に達する）と完全に一致する。

### 4.3 Q3 — 三分位分解（解釈に欠陥があるため結論には使わない）

> **この節は §4.6 に置き換える。** θ_react の三分位はペルソナ型の情報を捨てるため、
> 低θ層の中に clip しうる型（conformist / cautious の下側）と clip しえない型
> （reactant / independent）が混ざる。したがって層別の寄与度の数字は無効とする。
> 参考記録として数値は残す。

theta_react をシード内で三分位で層分けした結果（30 シード平均）。

| W | 低θ層 W_eff | 低θ層 潰れ率 | 高θ層 W_eff | 高θ層 潰れ率 |
|---|---|---|---|---|
| 0.05 | 0.048 | 1.3% | 0.050 | **0.0%** |
| 0.25 | **0.148**（低層ピーク） | 23.7% | 0.250 | 0.0% |
| 0.45 | 0.095 | 51.4% | 0.450 | 0.0% |
| 0.60 | 0.037 | 70.5% | 0.600 | 0.0% |
| 0.75 | 0.006 | 89.3% | **0.689**（高層ピーク） | 0.0% |
| 0.90 | **0.000** | **100.0%** | 0.609 | 0.0% |
| 1.00 | **0.000** | **100.0%** | 0.512 | 0.0% |

- **低 θ 層は W=0.90 以降 100% が `W_eff == 0`。**
  ただし「完全に介入を受け付けなくなる」の正確な意味は、制度的増分
  `w_sys·W_eff` がゼロになることである。`R` には社会経路 `w_sns·S_R` と基底 `b`
  が残るため、`R` が完全に動かなくなるわけではない。
- **高 θ 層はどの W でも潰れ率 0.0%。** `W_eff` は W=0.75 で 0.689 に達し、
  W=1.0 でも 0.512 を維持する。
- 低 θ 層の平均転倒数も 0.0255（W=0.35–0.40 がピーク）から 0.0167（W=1.0）へ減少する。
  高 θ 層の転倒数ピークは 0.0152（W=0.70）。
- この層別数値自体は再現するが、層の内訳が clip 可否を混ぜるため、減少の帰属には使わない。

したがって三分位分解だけでは「強い介入ほど反発する人には効かない」とは言い切れない。
帰属の確定は §4.6 のペルソナ別結果による。

### 4.4 Q5 — 追加発見: 天井効果は介入側で再発する（当レポートの記述を訂正）

当初想定していなかった系統的な効果である。C2 の判定式 `clip率 = n_clipped_R / total_cells < 0.05`
に照らして、上側クリップ（天井）と下側クリップ（床）を分離して全ターンで数えた。
正しい分母は `T_max*n = 50000`（`n_clipped_R` はターン 1..T_max しか数えないため）。

| W | 0.45 | 0.50 | 0.55 | 0.60 | **0.65** | **0.70** | **0.75** | **0.80** | **0.85** | 0.90 | 1.00 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| C2 の clip率 | 0.00066 | 0.00895 | 0.02091 | 0.04316 | **0.06577** | **0.07543** | **0.07081** | **0.06650** | **0.05320** | 0.03689 | 0.01263 |

- 床（下側クリップ）は**全 W で 0 件**。クリップはすべて天井側である。
- **W=0.65–0.85 の 5 水準で C2 の 5% 閾値を超過**し、ピークは W=0.70 の **7.54%**。
- 天井が最初に現れるのは **W=0.45**。

> **訂正（第 1 章「読み方のポイント」の C2 項、および §3.4）**
> 前回は「介入ありでのクリップは別枠のため、本実験中に同条件が再発することはない」と
> 述べたが、**これが誤り**である。段階0の C2 = 0.0000 は W=0 のみを測った値であり、
> 介入ありでは最大 7.54% まで `R` が頭打ちになる。
> `summary.n_clipped_R_treat` は記録されているため検出自体はできるが、
> C2 の合格（クリップ率 0.0）を本実験の前提として流用してはならない。

天井と潰れは W=0.45–0.60 で重なっている。天井は W=0.45 で初めて発生し、
ちょうど `W_eff` が最大近傍（母集団平均ピークは W=0.60 の 0.3599）のあたりから効く。
両者が競合して E_rate のピークを W=0.45–0.55 に押し下げている構造である。
W=1.0 で天井率が再び下がる（1.26%）のは、潰れによって `R` が上がらない人が増えるためで、
それ自体は整合的である。

> **指標の区別（重要）**
> 上の 7.54% は C2 が実際に判定に使う指標（全ターン clip 率）である。
> 一方、T\* という1断面だけを見て `R == 1.0` の人数を数えると 7.57% となり、
> 両者は同じ指標ではない。T\* 断面の値は全ターン値の近似としてしか使えないため、
> C2 の合否判定には必ず全ターン clip 率を使うこと。

> **結論の置換**
> §4.3 の三分位分解で述べた寄与度の数字（中θ層が約7割など）は**無効**とする。
> clip 不可能群だけでも「増加→平台→減少」の山が残り、同時に `W_eff=0` が確認でき、
> 同群自身の clip は全点ゼロである。したがってこの群の山を
> 「`R` が 1.0 に張り付いたこと」で直接説明することはできない。
> **リアクタンスの説明が残る。**
> ただし不可能群は `R` の可動域自体が狭い（R_raw 上限が 0.50–0.65）ため、
> 「効果が小さいまま頭打ちしているだけ」の可能性は完全には除去できない。
> この留保が残る。

### 4.5 実務上の含意

1. **現行の `W_values = [0, 0.25, 0.5, 0.75, 1.0]` では機構を判別できない。**
   ピーク（0.45–0.55）は 0.5 にたまたま載っているが、0.75 と 1.0 は
   「減少局面」かつ「天井が 5% 超」の領域に当たる。主図に載せるなら 0.05 刻み、
   または `[0, 0.2, 0.45, 0.6, 0.8, 1.0]` のような刻みを推奨する。
2. **論文の主張は「逆 U 字型」とし、根拠は §4.6 の clip 不可能群に置く。**
   不可能群では天井が原理的に起きず、同時に `W_eff=0` が確認できる。
   表現は「完全に介入を受け付けなくなる」ではなく、
   「**制度的増分がゼロになる**（社会経路は残る）」とする。
3. **ペルソナは変更しない。Phase B（診断専用の clip バイパス）は現時点では不要。**
   不可能群の結果で「天井ではなく機構」の切り分けは足りている。
   追加が必要になった場合も診断専用ラッパーに留め、`b` や `w_sys` の変更はしない。
   前提1・前提2の検証範囲（C1–C4、30シード、14項目）を崩さないためである。
4. **Ablation の追加検証は未実施。** `ABL-SYS` では制度経路が消えるため効果が消えるはずであり、
   `ABL-REACT`（k=0, `W_eff = min(W,θ)`）では潰れが消えて θ で頭打ちになるはずである。
   **この2点は未検証**なので、主張にするなら追加実行が必要。
