> B2 非単調性の機構切り分け (mu=0.80, seeds 0-29, 0.05刻み):
>   baseline : ピーク W=0.60 (|E|=0.21100), 平均W_effの山 0.3599。非単調有意 d=-0.09333。
>   no_clip  : Rの[0,1]クリップを外してもほぼ同一。ピーク W=0.60 (|E|=0.21133)。非単調有意。
>              -> 非単調性は R の可動域制約が原因ではない。
>   theta05  : 全員 theta_react=0.5。W_eff=min(W,1-W) でピーク W=0.50 (|E|=0.27067)、
>              W=1.0 で E=0。E_rate は平均W_effのほぼ決定関数 (W_eff=0.05 の W=0.05 と W=0.95 が
>              ともに E=-0.0297)。
>              -> ピーク位置は theta_react 分布が決める。非単調性は W_eff=min(W,(1+k)theta-kW)
>                 の山型と E_rate=f(W_eff) から直接出る。
>
> C ロバストネス (mu=0.80, W刻み0.1)。非単調が保たれるか:
>   persona (n_seeds=15): A peakW=0.50 / B peakW=0.60 / C peakW=0.60。3種すべて山が残る。
>   net (n_seeds=15)    : WS peakW=0.50 / ER peakW=0.60 / BA peakW=0.50。3種すべて山が残る。
>                         平均W_effはネットワーク種類に依らず同一 (W依存のみ)。
>   N (WS)              : N=50 peakW=0.60 (n_seeds=15), N=200 peakW=0.60 (n_seeds=15),

>   -> 非単調性はモデル機構 (リアクタンス) に由来し、規模・トポロジー・型構成に頑健。
